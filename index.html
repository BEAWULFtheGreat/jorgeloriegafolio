My Work

DATA CLEANSING

I work extensively with data, focusing on transforming raw, unstructured, and often imperfect datasets into reliable, meaningful information that supports analysis, prediction, and real-world applications. My process involves meticulously examining data for issues such as missing values, duplicates, inconsistencies, and outliers, then applying structured techniques to clean and standardize it for further use. Using Python specifically libraries like Pandas and NumPy I perform data manipulation, preprocessing, and visualization to identify patterns and communicate insights effectively. I also implement machine learning techniques, such as Linear Regression and K-Nearest Neighbors (KNN), for both prediction and classification tasks while leveraging them in preprocessing workflows like data validation and imputation. To further explore data structure, I apply clustering methods including K-Means for grouping, DBSCAN for noise detection, and Hierarchical Clustering for identifying relationships. Additionally, I use SQL to manage structured data through queries, joins, and aggregations. My work ensures that data is clean, interpretable, and ready to support intelligent systems.

Skills: SQL, Python (Pandas, NumPy, Matplotlib)

Soft Skills: LangChain, Excel
